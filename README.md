## 二、价格对比（以 Claude 旗舰为例）

以 Claude Opus 系列（约官方 $5 / $25 per 1M tokens）为基准，加权均价按输入 30% + 输出 70% 粗算（单位：¥ / 百万 tokens）。不同站内部汇率和缓存支持差异很大：

- **灵眸AI**：约 ¥6 / ¥30（输入/输出），加权均价约 ¥22.8，支持缓存，Claude Code 友好。目前公开评测中性价比极高。
- **PackyAPI / PackyCode**：约 ¥30 / ¥150 左右（部分渠道更低），支持 Claude Code，价格中等偏高。
- **AIHubMix**：接近官方汇率（约 ¥7.1/$），Claude Opus 约 ¥35.5 / ¥177.5，模型多，有免费测试额度。
- **OpenRouter**：官方价 + 少量加价，需科学上网，海外聚合首选。
- **其他特价站**（如部分 0.1x～0.5x 渠道）：价格可低至官方的 1～3 折，但常伴随「逆向 / 订阅切片 / 渠道不透明」风险，稳定性波动大。

**注意**：
- 真正影响账单的不只是标价，还有**缓存命中率**、**是否降智/掺水**、**失败重试**。
- 低价站要重点看「实测扣费是否对得上」和「模型真伪验证」（推荐用独立检测站）。

ClaudeMix 走的是统一网关 + 按量付费路线，价格处于中等透明档，重点不在「最低价」，而在**一个 Key 覆盖多模型 + 实时用量监控**。

## 三、稳定性与可用性

- **高稳定性阵营**：AIHubMix、部分老牌聚合站、OpenRouter。公开检测中可用率较高，有负载均衡和故障切换。
- **高性价比但波动较大**：部分特价 Claude 专用站。便宜时很香，但容易出现域名更换、渠道调整、偶发降智。
- **检测数据参考**：Veridrop 等独立站会持续跑 Claude / OpenAI / Gemini 协议检测，优先选「多次实测、中位分稳定、严重问题少」的站点。

稳定性建议：
1. 先小额充值实测 1～2 天。
2. 看是否支持 Prompt Caching（对 Claude Code 成本影响巨大）。
3. 观察客服响应和公告透明度。
